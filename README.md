# 🧠 Process Scheduler Simulation

A Python-based desktop application that simulates CPU scheduling algorithms and visualizes process execution using Gantt charts.

## 🚀 Features
- FCFS, SJF, Priority Scheduling (RR in progress)
- User-friendly Tkinter GUI
- Dark mode + styled widgets
- Gantt chart visualization using Matplotlib
- Error handling for input validation
